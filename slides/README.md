# 📊 Hardware AI Acceleration — Slides & Presentations

Presentation layer for the **Hardware AI Acceleration & Tensor Core Engineering** curriculum (Labs 00–08): PowerPoint decks, a live browser presenter, and Marp slide sources.

---

## 🚀 Quick Start

```bash
# Live interactive browser presenter
python3 slides/serve.py
```

Open **http://localhost:8000** — downloadable `.pptx` decks are linked inside the app.

## 📥 PowerPoint Decks

Decks are generated by the slide builder (run from the **repo root**):

```bash
python3 slides/generate_pptx_slides.py
```

## ⚡ Interactive Browser Presenter

Run `python3 slides/serve.py` to launch the animated web deck:

* **Interactive Adder Simulator** — live two's-complement overflow & saturation clamp.
* **Systolic Wavefront Grid** — step-by-step matrix flow across 16 PEs.
* **KaTeX Rendering** — crisp formulas for attention scaling and base-2 decomposition.
